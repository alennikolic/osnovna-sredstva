# 📦 Aplikacija za Osnovna Sredstva

Aplikacija za vođenje evidencije osnovnih sredstava realizovana u PHP-u i MySQL bazi podataka, usmerena na lak rad u lokalnom razvoju korišćenjem **Docker Compose** okruženja.

---

## 🛠️ Zahtevi sistema

Pre pokretanja potrebno je da na vašem Linux sistemu imate instalirane sledeće komponente:
* **Git**
* **Docker**
* **Docker Compose** (V2 dodatak ili samostalna verzija)

---
